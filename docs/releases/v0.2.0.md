# v0.2.0

**Release Date:** 2026-11-13

Recorded narration joins the format. A recording tool can store each
lesson's synthesized narration beside its deck, and a platform can play that
audio with the slides, knowing exactly when the recording no longer matches
the narration.

## Highlights

- **Recorded narration beside a deck:** `deck/recordings/recordings.json`
  lists each lesson's recording per language: its MP3, WebVTT captions,
  voice, and where each slide starts in the audio
- **Recordings know when they're out of date:** each slide's narration
  fingerprint is stored with the recording, so editing a slide's narration
  or pause, or adding, removing, or reordering slides, marks exactly that
  lesson stale; restyling a slide doesn't

## Added

- Recording types in the `deck` package: `Recordings`, `LessonRecording`,
  `RecordedSlide`, and `RecordingVoice`, with `ReadRecordings`, `Write`,
  `Find`, `Set`, and `CheckPaths`
- `deck.NarrationFingerprint`, `Lesson.SlideNarration`, and
  `Lesson.CheckRecording`, which reports a recording as `current`, `stale`
  with the changed slides, or `missing`
- `Section.Recordings`, loaded with the section
- Each deck lesson's recording status per language in the lessons report,
  and in `coursespec lessons`
- Validation of recordings: `unknown-lesson`, `recording-language`,
  `duplicate-recording`, `invalid-recording`, and `missing-file` errors, and
  a `stale-recording` warning
- `recordings.schema.json`, generated, embedded, and printed by
  `coursespec schema recordings`

## Format decisions in this release

- Recordings live in `recordings/` beside the deck, like its transcript in
  `voiceover/`, and their paths must stay inside it
- Audio is MP3, which every browser plays; captions are WebVTT
- A recording stores what it was recorded from, not when: a narration
  fingerprint per slide, so status is computed from files in any clone
- The default language's fingerprint covers the deck's narration and its
  pause; a translation's covers the transcript's text

## Installation

```bash
go install github.com/academyosio/course-spec/cmd/coursespec@v0.2.0
go get github.com/academyosio/course-spec@v0.2.0
```

## Upgrading

No changes are needed to existing courses. Courses without a `recordings/`
directory load, validate, and report as before.
