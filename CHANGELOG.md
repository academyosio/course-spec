## [v0.2.0] - 2026-11-13

### Highlights

- Recorded narration beside a deck: `deck/recordings/recordings.json` lists each lesson's recording per language, with its MP3, WebVTT captions, voice, and each slide's start time, so a platform can play recorded audio with the slides
- Recordings know when they're out of date: each slide's narration fingerprint is stored, and `CheckRecording` reports a recording as current, stale with the changed slides, or missing

### Added

- `deck` recording types (`Recordings`, `LessonRecording`, `RecordedSlide`, `RecordingVoice`) with `ReadRecordings`, `Write`, `Find`, `Set`, and `CheckPaths` ([`2f46e46`](https://github.com/academyosio/course-spec/commit/2f46e46))
- `deck.NarrationFingerprint`, `Lesson.SlideNarration`, and `Lesson.CheckRecording`: a recording is current only while its slides are the lesson's, in order, each recorded from its narration as it is; restyling a slide keeps it current ([`2f46e46`](https://github.com/academyosio/course-spec/commit/2f46e46))
- Sections load their recordings (`Section.Recordings`), and the lessons report gives each deck lesson's recording status per language, shown by `coursespec lessons` ([`b4320de`](https://github.com/academyosio/course-spec/commit/b4320de))
- Validation of recordings: unknown lessons and languages, duplicate entries, paths outside `recordings/`, missing files, timings that don't tile the audio, and a `stale-recording` warning ([`b4320de`](https://github.com/academyosio/course-spec/commit/b4320de))
- Generated `recordings.schema.json`, embedded and printed by `coursespec schema recordings` ([`d9859ce`](https://github.com/academyosio/course-spec/commit/d9859ce))

### Documentation

- Recorded narration in the decks and narration guide, its findings in the validation reference, and its schema in the schemas reference ([`1dafa7c`](https://github.com/academyosio/course-spec/commit/1dafa7c))
- v0.2.0 release notes

## [v0.1.0] - 2026-10-27

### Highlights

- One directory per course: course.json, a section.json per section, HTML decks with narration, translations, pronunciations, quizzes with answer keys, and published state, all JSON with camelCase properties
- Lessons discovered from decks: a slide with `data-lesson` starts a lesson and its `data-id` is the lesson's stable ID, in videoascode's deck conventions
- `coursespec validate` reports every problem with its file, location, code, and fix, as text or JSON, for one course or every course beneath a directory
- Content fingerprints of each lesson's slides and narration in every language, so `coursespec lessons` reports what changed since it was published, even in a fresh clone

### Added

- Go types for the course and section manifests, lessons, quizzes, pronunciations, and published state ([`6540591`](https://github.com/academyosio/course-spec/commit/6540591))
- `deck` package: slides, lessons, narration with `[PAUSE:ms]` directives, the files a deck loads, transcript matching by slide ID or position, and content fingerprints ([`a7c8123`](https://github.com/academyosio/course-spec/commit/a7c8123))
- `coursespec.Load` resolves a course directory into one value with strict decoding, lessons discovered from decks, translations, quizzes, pronunciations, and published state; `coursespec.Find` lists every course beneath a directory; planned sections load without their files ([`13f47b4`](https://github.com/academyosio/course-spec/commit/13f47b4))
- Generated, embedded, and linted JSON Schemas for course.json, section.json, quiz.json, and published.json ([`c3e84d9`](https://github.com/academyosio/course-spec/commit/c3e84d9))
- `validate` package: schema, ID, section, deck, transcript, quiz, change-log, and published-state checks, with warnings for unnarrated slides, long lessons, remote deck files, missing translations, answer patterns, and unversioned changes; publish status for each lesson and quiz ([`c767c7d`](https://github.com/academyosio/course-spec/commit/c767c7d))
- `coursespec` command: `validate`, `lessons`, and `schema`, with text and JSON output ([`3b22177`](https://github.com/academyosio/course-spec/commit/3b22177))
- A platform `revision` in published state and `coursespec.WritePublished` ([`dd050c0`](https://github.com/academyosio/course-spec/commit/dd050c0))
